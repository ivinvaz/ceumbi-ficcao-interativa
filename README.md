# Sobreviva ao CEUMBI!

Uma ficção interativa de sobrevivência zumbi, feita em JavaScript puro. Você lê a situação, escolhe o que fazer e descobre as consequências. Existem vários finais, mas só um deles é realmente bom.

## Como jogar

1. Abra o `index.html` no navegador.
2. Leia o texto da cena e escolha uma das opções abaixo dele (no máximo 4).
3. Use o botão **⬅ Voltar** para retornar à cena anterior. Em algumas cenas não há volta.
4. Explore, descubra onde estão os itens e em que ordem as coisas precisam acontecer.
